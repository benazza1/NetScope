# NetScope PRO v2.0

Lightweight Network Analysis & Learning Tool (CLI)

## Features
- View network neighbors (ip neigh)
- Packet simulation
- Network statistics
- Device discovery (LAN)
- Simple CLI interface

## Commands

- help → Show commands
- about → About tool
- scan → Demo packet scan
- stats → Statistics
- devices → Network devices
- clear → Clear screen
- exit → Exit tool

## Installation

```bash
python3 netscope.py
